The **Network Manager** in Linux systems can be managed using (1) the Graphical Tool - if a Graphical Desktop Environment is installed, (2) the command **nmcli**, and (3) the text-based user interface **nmtui**. </br>  
Having worked in Windows environments, **nmtui** is similar to the **sconfig** utility present in Windows Server Core. </br>
