# LFS200: Fundamentals of Open Source IT and Cloud Computing — Study Notes

A record of the hands-on lab work completed during the Linux Foundation's [Fundamentals of Open Source IT and Cloud Computing (LFS200)](https://training.linuxfoundation.org/training/fundamentals-of-open-source-it-and-cloud-computing-lfs200/) course. Only chapters with practical terminal work are documented here. Conceptual chapters are studied but not included in this repository.

**Started:** 03-June-2026

---

## About This Repository

LFS200 covers both conceptual and practical content. Chapters on cloud computing models, project management, open source licensing, and introductory theory are studied through the course but not documented here. This repository covers only the chapters that involve real terminal work — filesystem navigation, user administration, networking commands, security tools, and DevOps tooling — where
there is something concrete to show: actual commands run, real output, and problems encountered and solved.
