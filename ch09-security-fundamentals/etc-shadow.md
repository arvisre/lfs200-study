# "/etc/shadow" </br>  
The **"/etc/shadow"** file or simply **shadow** file contains the passwords for the user accounts in a system. Passwords are not stored in plaintext format - they are encrypted. </br>  
I have created a user account **tech01** to demonstrate the fields in the **shadow** file. </br>
