# DevOps Basics </br>  
DevOps, an evolution of Agile methodology, is a set of practices, combining software development (Dev) and IT operations (Ops). DevOps aims to reduce the systems development life cycle: build, test, and release software faster and more reliably. </br>  

### The seven practices of DevOps are: </br>  
1. Configuration Management - practice of controlling and managing changes to software.  
2. Continuous Integration - practice that allows developers to frequently share code into a central repository, where builds and tests are run and feedback can be obtained.  
3. Automated Testing - practice of using software to execute automated tests to reduce the burden of manual testing and the time taken.  
4. Infrastructure as Code - practice of provisioning and managing IT infrastructure automatically through code.
5. Continuous Delivery - practice that ensures that changes to software code are built, tested, and prepared for production release.
6. Continuous Deployment - practice of automating code release directly into production without a manual intervention.
7. Continuous Monitoring - practice of proactively monitoring performance, usage, and errors and alerting about the health of the application/production environment. </br>
