# Multiple Users working on one file </br>  
For this demo, let us assume that the user "**tech1**" wants to contribute to the file "**my-code**". For this purpose, I have created an identity for user "tech1". </br>  
git config user.name "tech1"  
git config user.email "tech1(at)home.lab" </br>  
Using the above commands an identity for "tech1" has been created. I have intentionally not used the option "**--global**" for the above commands. The creation of the identity can be confirmed as shown in the image below:   </br>
